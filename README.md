# Plataforma Escolar (Next.js + Supabase)

## Pasos para arrancar:
1. Renombra `.env.local.example` a `.env.local` y pega tu `NEXT_PUBLIC_SUPABASE_ANON_KEY` (`sb_publishable_...`).
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre `http://localhost:3000` en tu navegador.
